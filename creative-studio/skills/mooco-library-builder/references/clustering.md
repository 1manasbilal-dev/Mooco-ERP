# Clustering inspiration into styles

## Group by look, tag by purpose

A style is a **visual language** you could apply to any Mooco product: imagery type + light + color mood + layout rhythm + type feel. Two posts with different purposes (a sale and a recipe) can share a style; two sale posts can be in different styles. Purpose stays a tag.

## Method

1. Lay out all cards; first split by **imagery type** (real photo / 3D render / illustration / flat graphic / collage).
2. Within each, split by **light & color mood** (bright airy / warm homely / dark premium / bold saturated / pastel soft).
3. Then check **layout rhythm** (big product hero / text-led / grid / asymmetric collage).
4. Merge groups that would produce the same Gemini prompt; split groups whose prompts would differ a lot.
5. Aim for **6–10 styles**. A style needs **at least 5 examples**; smaller groups go to `02_Emerging`.
6. Images that teach nothing Mooco can use (pure UI screenshots, illegible, duplicates) → mention them and suggest moving them to `02_Emerging` with tag `low-fit`; the owner decides.

## Naming

Short, memorable, Roman Urdu/English mix, describing the look not the purpose: "Soft 3D Pastel", "Splash Studio", "Desi Flat Illustration", "Bold Type Poster", "Dark Golden Premium". Avoid naming styles after other brands.

## Proposal message format (to the owner)

```
[N] images dekhi, [K] styles ban rahi hain:

1. [Style name] — [one-line identity] — [count] posts (#3, #7, #12…)
   Mooco mein: [best-fit product/post type]
2. …

Emerging (5 se kam): [names + numbers]
Low-fit: [numbers + reason]

Kya ye theek hain? Naam badalne, merge ya split karne hain to bata dein.
```

Send one contact sheet per proposed style if you can make them; it is much easier for the owner to judge pictures than names.

## Mapping to house styles

If an inspiration style is very close to a house style (Doodh Fresh, Desi Kitchen, Lime Pop, Golden Raat), propose adding its best images as **reference images** of that house style instead of creating a duplicate style.
