# Monthly review

Goal: move from "styles the owner likes" to "styles that sell", and keep the library fresh.

## 1. New inspiration
- List `00_Inbox`. For each new image make a Style DNA card.
- Fits an existing style → move it there (renamed with the next number).
- Doesn't fit → `02_Emerging` with tags.
- Any Emerging group with 5+ examples → propose it as a new style (owner approves) and write its guide.

## 2. Post Log learning
Read the `Post Log` sheet (Drive `read_file_content` gives a sample; ask the owner to paste or export the full sheet if it is long). For rows with results:

- **Engagement score** per post = likes + 2×comments + 3×shares + 3×saves (use what is filled; reach normalizes if available: score / reach × 1000).
- **Orders/DMs** are the strongest signal — report them separately.
- Compare averages by **style**, **concept level** (Safe/Bold/Wild), **product**, **purpose** and **day**.
- Only call a difference real if each group has at least 3 posts; otherwise say "abhi data kam hai".

Report in Roman Urdu, max 6 bullets: top style, weakest style, best concept level, best day/product, one surprise, and 2–3 concrete changes for next month (e.g. "Golden Raat ghee posts 2× better — har hafte ek ghee post rakhein").

## 3. Update the library
- Write the findings into each style's "Performance notes".
- Adjust guidance in `mooco-style-library` SKILL.md ("How to choose") if a clear pattern holds.
- Suggest moving Mooco's best 1–2 posts of the month into `04_Own-Winners`; they become the strongest references of their style.
