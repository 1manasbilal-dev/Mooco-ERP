# Style DNA card

One card per inspiration image. Short phrases, not sentences.

```
#[number] [Drive file name]
Look:        [3–5 words, e.g. "soft 3D pastel product hero"]
Layout:      [product position · text position · grid/asymmetry · negative space]
Colors:      [dominant 2–3 colors as names/hex · light/dark · saturation]
Type:        [headline font feel: rounded/serif/script/condensed · size contrast · case]
Imagery:     [photo / 3D render / illustration / flat graphic / collage · angle · props]
Light:       [soft daylight / studio / dramatic low-key / flat]
Mood:        [3 words]
Purpose:     [sale / launch / showcase / recipe / festive / awareness / testimonial / other]
Copy:        [headline length & tone · CTA style] (if visible)
Steal this:  [the one thing Mooco should learn from it]
Mooco fit:   [high / medium / low] — [which Mooco product or post type]
Tags:        [6–10 lowercase tags, e.g. 3d, pastel, product-hero, splash, rounded-type, minimal]
```

Drive description (max ~450 characters) = `Look · Purpose · Mooco fit · Tags` from the card.

## Notes

- "Steal this" is the most important line: it is what the owner liked, even if they didn't say it.
- If the owner put words in the file name (e.g. `colors-splash.jpg`), treat them as the reason they liked it and reflect it in "Steal this".
- Video screenshots: judge the frame and note "video" in tags.
- Low Mooco fit is fine — the image may still teach layout or typography.
