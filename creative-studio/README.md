# Mooco Creative Studio

Mooco ki social media posts ke liye AI ka poora system: brand ki pehchaan, styles, aur idea se le kar tayyar Post Package tak.

## Skills

| Skill | Kaam | Kab chalti hai |
|---|---|---|
| `mooco-brand-kit` | Logo, colors, fonts, zabaan ka andaaz, products, occasions, rules | Har Mooco kaam mein khud |
| `mooco-style-library` | Post ki styles (abhi 4 house styles: Doodh Fresh, Desi Kitchen, Lime Pop, Golden Raat) | Har post mein |
| `mooco-post-studio` | Idea/photo → Brief → Style → 3 Concepts → Design → QA → Gemini prompt + Canva text + caption | "Post banao", "offer post chahiye", "hafte ka plan" |
| `mooco-library-builder` | Inbox ki pasand ki posts analyze karke styles banana, monthly review | "Inbox analyze karo", "mahine ka review" |

## Install (Claude app)

1. Claude ne jo `.skill` files bheji hain, un ke card par **Save skill** button ho to us se save karein.
2. Button na ho to file download karein aur Claude app ki Settings mein Skills wale hisse se **upload** karein. Chaaron skills chahiye.
3. Chat mein **Google Drive connector** on rakhein, library builder aur Drive files ke liye.

## Roz ka istemal

- **Ek post:** `Dahi ki post banao` (+ product photo ya idea). Jaldi ho to `express` likh dein.
- **Hafte ka plan:** `Is hafte ki 5 posts plan karo`.
- **Sirf ek hissa:** `Sirf caption do` · `Bas Gemini prompt do` · `3 concepts do`.
- **Image check:** Gemini wali image bhejein → Claude batayega kya theek karna hai aur isi Gemini chat mein kya likhna hai.
- **Post ke baad:** Post Package ki aakhri line `Post Log` sheet mein paste karein, 3–7 din baad results bharein.
